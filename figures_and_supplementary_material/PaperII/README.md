# Paper II submission release

Manuscript and SI correspond to 1,636,322 residues and 7,938 PISCES-consistent analysed chains. The final CSV is provided as a compressed release asset, with its uncompressed SHA256 in supporting_data/DATA_MANIFEST.json. Paper II code and numerical evidence are in paper2_data_and_code.zip. Corrected analysis scripts retain the suffix _pisces; Figure 4 uses paper2_F3_assembly_v2.py with --panel_d_feature bfactor_ca.

Relaxation audit: 374 exact plus 2 same_seq results retained; 390 results absent from the analysed feature-chain set and 12 diff_seq excluded. Candidate-selection history is not inferred. Candidate residue membership after quality filtering remains unverified. Residue-level bootstrap, train/test split and SEM do not establish structure-level independence. Automatic mechanistic verdicts in raw logs are not adopted as manuscript conclusions.

A GitHub release provides version-specific data and code. No Zenodo DOI is claimed. Add an archive DOI after the data and code have actually been deposited. Co-author approval of the exact manuscript remains an author responsibility.
